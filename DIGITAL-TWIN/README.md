## 三、三份材料之间的关系（重要）

这三份材料是**同一条产品线的三个视角**，但写的时候彼此不完全知情，因此存在需要弥合的差异：

| | `product_plan.md` | `微信数据对外接入文档.md` | `数字分身_Agent开发说明_v1.md` |
|---|---|---|---|
| **视角** | 产品要什么 | 上游有什么 | 工程怎么做 |
| **对数据的前提** | 「已有本地机器人能够取得微信历史与每日聊天记录」 | `chat_history/` 目录**不存在**，18 条事件全是同步失败，friends=0 | 明确写「数据准备不足」，需先过 P0/P1 门槛 |
| **对 YoBot 的定位** | 未提及 | 只读上游，含红线清单 | 只读上游，禁止写入与代转发 |

**注意第一行和第二行的矛盾**：产品方案假设数据已经有了，而接入文档证明它还没有。这个矛盾是 `PLANNING/01-数据现实与P0门槛.md` 要处理的核心问题。
