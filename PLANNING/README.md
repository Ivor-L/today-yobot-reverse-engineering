# PLANNING — 数字分身 × YoBot 规划输入包

这个目录**不做计划，它让计划能做得好**。用途：把网页版 GPT 变成一位能读懂现实的架构负责人，产出一份可排期的开发计划。

---

## 一之二、三层架构来自哪里

`06` 里的三层不是凭空设计的，是三轮源码核验得出的结论：

| 层 | 来自 | 关键证据 |
|---|---|---|
| 执行层 | **YoBot** | `agent/` 145 模块、`scheduler/` 9、`channels/` 11 |
| 记忆层 | **Today 范式** | Markdown VFS + `MemoryActivity` 版本快照 + 可浏览资产 |
| 知识层 | **WeKnora** | `docreader/parser/` 26 个解析器、RRF 融合 + rerank、`wiki_page_revisions` 溯源 |

**核心判断**：世界知识进检索（找得到），私人记忆走文件（说得准）。**用向量召回取记忆是结构性错配。**

## 三、已经定下的三件事（不要再纠结）

1. **数字分身的六页功能加进 YoBot**，不另起独立产品。YoBot 现有销售功能保留。
2. **合规暂不拍板，先做验证**。数据层设计成**可替换的适配器接口**，隔离对逆向组件的依赖；首版交付物不含逆向组件。
3. **第一阶段先攻数据打通。** 没有真实消息，六页面全是空壳。

## 四、三步流程

### 第 1 步：读 `01` 与 `05`（约 20 分钟，自己做完）

- **`01`** 告诉你真正的阻塞在哪。读完你会知道：产品方案假设的「已有微信历史」**不存在**。
- **`05`** 有四张关键表：分层归属图、六页面落地路径（**哪三页可以零消息先做**）、D0–D7 决策点、P0–P4 路线图。

**不必现在把 D0–D7 全部决定**，但要能回答「我倾向哪个」和「哪个我还不知道」。GPT 拿到倾向，输出的才是有立场的方案，而不是八个选项各写一遍。

### 第 2 步：把提示词扔给 GPT

打开 `00-给GPT的提示词.md`，复制 `---` 之间的全部内容。

- **GPT 能访问本仓库** → 直接粘贴，它会自己核对文件
- **GPT 不能访问** → 粘贴提示词 + 上传 `01`–`05` 五份文档 + `DIGITAL-TWIN/product_plan.md` + `DIGITAL-TWIN/微信数据对外接入文档.md`

**建议用推理模型**（o 系列 / GPT-5 thinking / Claude extended thinking），开新对话。这类任务最怕上下文里混入无关历史。

**不要一次问完。** 第一轮拿到的应该是**带决策点的粗计划**，然后按提示词末尾的追问模板逐层往下钻。追问比重新提问有效得多。

### 第 3 步：用事实底稿做交叉验证

GPT 会不可避免地产生幻觉。用 `02` 当验伪工具：

| 如果 GPT 说 | 去核对 |
|---|---|
| 「YoBot 没有记忆系统」 | 错。`recovered/app/dist/electron/memory/` 有 14 个模块 |
| 「需要新建知识库能力」 | 错。`knowledge/` 已有配额与容量核算 |
| 「YoBot 没有 MCP 支持」 | 错。`skills/mcp/` 同时有客户端与服务端 |
| 「前端和内核耦合，要先解耦」 | 错。静态 SPA + 独立服务子进程，本来就是解的 |
| 「YoBot 已经有微信聊天数据」 | **错，而且是致命错误。** 见 `01` §二 |
| 「数字分身需要新建一套主动动作体系」 | 部分对。`scheduler/` 有机制（执行预设/变更意图/结果），缺的是产品化形态与 timing 反馈 |
| 提到任何「YoBot 已经在做 X」 | 要求它给出证据路径，然后去仓库核对 |

**判据**：凡是没有标证据路径的现状描述，一律当「未验证」处理。

## 五、三个不要忘的边界

**一、逆向产物不是源码工程。** `02` §二那 380 个模块能读、能作为设计参考，但**从未启动运行过**。任何「YoBot 现在能做什么」的判断，都必须用真实运行验证来补。

**二、数据现实推翻了产品方案的前提。** `product_plan.md` 说「已有本地机器人能够取得微信历史与每日聊天记录」，而实测是：`chat_history/` 目录**不存在**、`friends=0`、18 条事件全是同步失败。**在 P0 通过之前，任何关于六页面「真实版」的承诺都是空的。**

**三、仓库不能设为公开。** 它含 `02-YoBot-WeChat-RPA/standalone/scripts/` 下的授权绕过脚本，以及本机路径、端口、进程名。

> **数字分身 = 把 YoBot 的业务层从「销售专用」重构为「场景可配置」，并在此之上长出六页通用表达。**
